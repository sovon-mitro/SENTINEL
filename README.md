# SENTINEL

### HTTP Security & CVE Scanner

SENTINEL is a Python-based security scanning tool designed to
identify web server technologies and detect potential
vulnerabilities using the National Vulnerability Database (NVD).

## Version

**v0.1.0**

## Features

- HTTP target scanning
- HTTP response information collection
- Web server detection
- Server product and version extraction
- Semantic version validation
- NVD API integration
- CVE identification
- Structured error handling

## Technologies

- Python
- Requests
- Regular Expressions
- NVD REST API

## Project Status

SENTINEL v0.1 is the initial development release.

## Disclaimer

SENTINEL is intended for authorized security testing,
educational purposes, and systems you own or have explicit
permission to assess.
